# Oujotape.github.io

Meu portfólio de projetos feitos com programação assistida por IA (vibe coding).

Site: https://oujotape.github.io

## O que tem aqui

- `index.html`: página única do portfólio, sem dependências (HTML e CSS puros).
- `automacao-organizador/`: script Python que organiza pastas por tipo de arquivo, com testes.
- `prompts/`: biblioteca de prompts estruturados e registro de experimentos com LLMs.

## Como atualizar

1. Edite a seção "Projetos" em `index.html`.
2. Para cada projeto novo, adicione um bloco `<article class="card">` com título, descrição e link.
3. Faça commit; o GitHub Pages publica sozinho em alguns minutos.
