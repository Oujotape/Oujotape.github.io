Como eu trabalho

  1. Entendo o problema. Antes de pedir código, defino quem vai usar e o que precisa funcionar.
  2. Construo com IA. Descrevo o que quero, gero a primeira versão e itero em passos pequenos.
  3. Testo e reviso. Rodo o resultado, procuro falhas e confiro o que a IA escreveu.
  4. Publico e documento. Todo projeto vai para o GitHub com um README explicando o que faz.
